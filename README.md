# Polgár · Mate in Two

Offline puzzle trainer for the mate-in-2 problems (#307–1074) from László Polgár's *Chess: 5334 Problems, Combinations and Games*.

- Positions: martinhaleyt's Lichess studies. Solutions: the book.
- `npm install && node build.mjs` bundles everything into `docs/index.html` (served by GitHub Pages; installable as an offline PWA).
